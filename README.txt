EasyReporter Portable Complete Version
======================================

This is a complete portable version of EasyReporter that includes:
- Full Python runtime environment
- All required dependencies
- Sample data and models
- Ready-to-use application

How to Use:
-----------
1. Double-click start.bat to launch the application
2. Wait for the application to start (may take a few moments)
3. Open your web browser and go to: http://localhost:8501
4. The EasyReporter interface will be available
5. Press Ctrl+C in the command window to stop the application

Features:
---------
- No Python installation required
- No internet connection needed for basic functionality
- Includes Cellpose models for cell segmentation
- AI-powered chart analysis and interpretation
- Multiple visualization types (bar charts, box plots, scatter plots)
- Flow cytometry simulation

Troubleshooting:
---------------
- If the application doesn't start, ensure start.bat is in the same folder as streamlit_app.py
- If you see "No Python runtime found", check that python_runtime folder exists
- For port conflicts, the application will try to use an alternative port
- Close any existing instances before starting a new one

System Requirements:
-------------------
- Windows 10 or later
- At least 4GB RAM recommended
- 2GB free disk space
